## Multi Page Website.

## 📌 | 🇺🇸 Description | 🇧🇷 Descrição  
 - 🇺🇸 | A multi-page website developed for Next.js studies. The project features client-side navigation, responsive design and an intuitive interface for users.
 - 🇧🇷 | Website com multiplas páginas desenvolvido para estudo de Next.js. Projeto possuí navegação client-side, design responsivo e uma interface intuitiva para o usuário. 

## 🎯 | 🇺🇸 Project purpose | 🇧🇷 Propósito do projeto 
  - 🇺🇸 | A practical project focused on multi-page and client-side navigation training in Next.js.
  - 🇧🇷 | Projeto prático focado no aprendizado de multiplas páginas e navegação client-side utilizando Next.js.

## ⚙️ | 🇺🇸 Technologies | 🇧🇷 Tecnologias
  - Next.js
  - TypeScript
  - CSS
  - HTML

## 🚀 | 🇺🇸 How to run the project locally | 🇧🇷 Instruções para rodar localmente
  > - 🇺🇸 | 1. Download the .zip file from the GitHub repository (https://github.com/Clique-N/Multi-Page-Website-Next.js).
  > - 🇧🇷 | 1. Faça o download do arquivo .zip no repositório do GitHub (https://github.com/Clique-N/Multi-Page-Website-Next.js).
  
  > - 🇺🇸 | 2. Extract the .zip file to a folder your computer, then open the project in VS Code.
  > - 🇧🇷 | 2. Extraia o arquivo .zip na pasta do seu computador, e em seguida abra no VS Code.

  > - 🇺🇸 | 3. Open the terminal and run the following command to install the dependencies: `npm install`.
  > - 🇧🇷 | 3. Abra o terminal e instale as dependências com o seguinte comando: `npm install`

  > - 🇺🇸 | 4. Start the project with following command: `npm run dev`.
  > - 🇧🇷 | 4. Rode o projeto com o seguinte comando: `npm run dev`.

  - 🇧🇷 | Trabalhar com estrutura de múltiplas páginas, navegação client-side utilizando next/link, organização e reutilização de components no projeto, e estilização responsíva com CSS Modules.
